# Cozy Studio v2 — implementation and data

The GitHub README is a native Markdown document with animated/static SVGs, responsive width handling, and individually clickable project image links. The illustrations and project summaries are deliberately editorial; quantitative GitHub activity and stars are not manually invented.

## Data updates

A GitHub Actions workflow runs on pushes to scripts or workflow files, by manual dispatch, and on a scheduled 30-minute cadence (GitHub schedules can be delayed, skipped, or disabled; image caches can lag). To see a new contribution, GitHub must first recognize that activity, then the next successful workflow must run, then GitHub's cached graphic must expire. **This is periodic near-real-time refresh, not continuous streaming.**

The script calls GitHub GraphQL for `contributionsCollection.contributionCalendar` and GitHub REST for public owned repository metadata, verified featured repository stars and forks. A failed API response fails the workflow instead of producing synthetic counts. Private repo details aren't displayed.

All metric cards are generated by `scripts/generate.py`, which imports `scripts/github_data.py` (the prior verified GitHub data loader) and `scripts/studio_art.py` (the illustrated SVG renderer).

## Responsive behavior

The hero, garden, journey, stats, toolbox, and footer use `width="100%"`; individual featured project SVG images have a 420-pixel nominal width and are subject to GitHub's image max-width rule, resulting in two columns on typical desktop README widths and wrapping/downsizing on narrower screens. The three social link images are identically sized and wrap on mobile. GitHub README sanitation means custom CSS media queries and client-side JavaScript are not available, so this is a faithful visual adaptation, not a pixel-identical interactive website.

## Integrity

GlitchVision is a gameplay/simulation visual anomaly triage project, not a self-driving vehicle system; its project art features a stylized game runner and an on-screen glitch. PACT is marked ongoing. No historical SEC eval scores, claimed production readiness, self-reported skill percentages, or unsourced backend test counts appear in the live visuals.
