# Cozy Studio v2 — implementation and data

The GitHub README is a native Markdown document with animated/static SVGs, responsive width handling, and individually clickable project image links. The illustrations and project summaries are deliberately editorial; quantitative GitHub activity and stars are not manually invented.

## Data updates

A GitHub Actions workflow runs on pushes to scripts or workflow files, by manual dispatch, and on a scheduled 30-minute cadence (GitHub schedules can be delayed, skipped, or disabled; image caches can lag). To see a new contribution, GitHub must first recognize that activity, then the next successful workflow must run, then GitHub's cached graphic must expire. **This is periodic near-real-time refresh, not continuous streaming.**

The script calls GitHub GraphQL for `contributionsCollection.contributionCalendar` and GitHub REST for public owned repository metadata, verified featured repository stars and forks. A failed API response fails the workflow instead of producing synthetic counts. Private repo details aren't displayed.

All metric cards are generated by `scripts/generate.py`, which imports `scripts/github_data.py` (the prior verified GitHub data loader) and `scripts/studio_art.py` (the illustrated SVG renderer).

## Responsive behavior

The hero, garden, journey, stats, toolbox, and footer use `width="100%"`; individual featured project SVG images have a 420-pixel nominal width and are subject to GitHub's image max-width rule, resulting in two columns on typical desktop README widths and wrapping/downsizing on narrower screens. The three social link images are identically sized and wrap on mobile. GitHub README sanitation means custom CSS media queries and client-side JavaScript are not available, so this is a faithful visual adaptation, not a pixel-identical interactive website.

## Integrity

GlitchVision is a gameplay/simulation visual anomaly triage project, not a self-driving vehicle system; its project art features a stylized game runner and an on-screen glitch. PACT is marked ongoing. No historical SEC eval scores, claimed production readiness, self-reported skill percentages, or unsourced backend test counts appear in the live visuals.


## Painted journey and public-star provenance

- The AI Engineering Journey displays the illustrated `assets/ai-journey-painted.jpg` banner, with five milestone signs visible on GitHub desktop and a matching text-only milestone sequence for narrow mobile screens.
- The live **public stars** total counts stars **received across all owned public repositories**, including nonfeatured repositories. It does not represent stars the user has awarded.
- `scripts/star_attribution.py` regenerates the README star-source links using actual GitHub REST results at every successful stats update; manual edits within `STAR_PROVENANCE_START` and `STAR_PROVENANCE_END` will be overwritten.
- The initial link to StoreSense was verified before shipping. The Python unit tests verify no-star and multiple-star scenarios.

## Cozy Studio Concept 2 — independently linked intro, dynamic painted garden, footer

The intro is split into a decorative static banner and three independently clickable illustrated PNG buttons linking to the existing portfolio, LinkedIn and email addresses. The duplicate "Hey there" greeting has been removed from the README because the original hero image already includes it.

The garden is **not** a static mockup: `scripts/render_concept2.py` paints a fresh 53–54-week, Sunday-aligned, per-day calendar and total using the official GitHub GraphQL contribution payload, over a decorative illustrated `assets/garden-scene.jpg` background. The sample heatmap and the static example count from the illustration are completely obscured by an opaque data panel. Last-updated time appears inside the rendered PNG and reflects the time of the authenticated data run. `--placeholders` writes a clearly labeled pending state with no sample metrics.

GitHub Actions regenerates and commits `assets/contributions-painted.png` alongside the existing SVG and project cards. It runs on script pushes, manual dispatch, and scheduled approximately 30-minute updates. The GitHub Actions service may delay schedules and GitHub image caching can delay the README image refresh; this is not continuous real-time streaming.

The new footer is the illustrated Himalayan sunset postcard with no Blog, Buy Me a Coffee or donation links. The existing project gallery, real stats, real star attribution, and painted AI Engineering Journey are preserved.
